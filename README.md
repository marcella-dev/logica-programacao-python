# 🚀 Meus Primeiros Passos na Programação com Python: Fundamentos & Lógica

Bem-vindo ao meu repositório de estudos! Aqui documento a minha jornada técnica, focando na resolução de problemas de lógica de programação, manipulação de estruturas de dados e automação de processos de negócios.

---

## 📁 Pipelines e Algoritmos Desenvolvidos:

* **📊 analisador_dados.py:** Pipeline analítico que coleta fluxos de dados numéricos, realiza higienização de caracteres (`.replace()`) e extrai indicadores estatísticos consolidados (Média, Máximo, Mínimo e Volume) estruturados em payloads de BI.
* **📦 gestao_estoque.py:** Sistema avançado de automação para controle de inventário da *DataCode Solutions*. Utiliza dicionários aninhados, valida consistência de banco de dados e computa algoritmos de agregação com *list comprehension* para extrair o valor patrimonial total do ativo.
* **💱 conversor_moedas.py:** Script de normalização cambial que consome a API pública *AwesomeAPI* em tempo real usando a biblioteca `requests`. Possui arquitetura resiliente com tratamento de erros e fallback local para cotações de contingência (USD e EUR).
* **📈 simulador_investimento.py:** Motor de cálculo financeiro isolado da camada de interface. Processa a evolução de juros compostos mês a mês e estrutura o histórico do fluxo de caixa em coleções de dicionários simulando registros relacionais.
* **🏠 analise_emprestimo.py:** Sistema de governança bancária que valida a concessão de crédito imobiliário avaliando a margem consignável (limite de 30% da renda). Retorna payloads estruturados com vereditos de auditoria.
* **💳 gerenciador_pagamentos.py:** Motor de regras de checkout que processa transações financeiras aplicando políticas comerciais dinâmicas (fatores multiplicadores de descontos e juros) parametrizadas em constantes limpas.
* **🔐 sistema_login.py:** Script focado em segurança de microsserviços. Controla e valida credenciais mascaradas limitando tentativas de login para mitigar vulnerabilidades e acessos indevidos.
* **🎮 jogo_adivinha.py:** Um jogo interativo que utiliza a biblioteca random para gerar números e time para melhorar a experiência do utilizador.
